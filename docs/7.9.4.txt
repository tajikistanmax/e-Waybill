## ПРИЛОЖЕНИЕ И. ИНСТРУКЦИЯ ПО НАСТРОЙКЕ СКЗИ

### И.1. Установка КриптоПро CSP

1. Скачать дистрибутив КриптоПро CSP 5.0+ с официального сайта.
2. Запустить установочный файл `cryptopro.exe` от имени администратора.
3. Выбрать язык установки (русский).
4. Принять лицензионное соглашение.
5. Выбрать компоненты для установки (рекомендуется: "Полная установка").
6. Дождаться завершения установки.
7. Перезагрузить сервер.

### И.2. Настройка КриптоПро CSP

1. Открыть панель управления КриптоПро CSP (Пуск → КриптоПро → Настройка).
2. Перейти на вкладку "Общие".
3. Установить галочку "Использовать сертификаты для подписи".
4. Перейти на вкладку "Алгоритмы".
5. Установить алгоритм ГОСТ Р 34.10-2012 (256 бит).
6. Сохранить настройки.

### И.3. Установка сертификатов УКЭП

1. Получить сертификат УКЭП в удостоверяющем центре (например, ФНС).
2. Скопировать файл сертификата (с расширением `.cer`) на сервер.
3. Открыть панель управления КриптоПро CSP → закладка "Сертификаты".
4. Нажать "Установить" → выбрать файл сертификата.
5. Установить в хранилище "Личные" (Personal).
6. Проверить установку: сертификат должен отображаться в списке.

### И.4. Проверка работоспособности

1. Открыть командную строку.
2. Выполнить команду: `csptest -keyset -csp` — проверка доступности СКЗИ.
3. Выполнить команду: `csptest -sign -std -prov` — проверка подписания.
4. При успехе система выведет сообщение "Test passed".
