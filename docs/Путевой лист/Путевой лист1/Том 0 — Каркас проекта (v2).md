# Государственная платформа управления путевыми листами

# Enterprise Technical Specification (ETS)

## Том 0. Каркас проекта (расширенная версия)

### 1. Назначение

Создание единой государственной цифровой платформы управления путевыми
листами для всех видов автомобильных перевозок.

### 2. Цели проекта

-   Полный отказ от бумажных путевых листов.
-   Единая национальная база.
-   Работа 24/7.
-   Высокая доступность.
-   Масштабирование до миллионов пользователей.

### 3. Основные принципы

-   API First
-   Cloud Native
-   Microservices
-   Domain Driven Design
-   Event Driven Architecture
-   Zero Trust Security
-   RBAC + ABAC
-   Offline First
-   Mobile First
-   Audit by Design
