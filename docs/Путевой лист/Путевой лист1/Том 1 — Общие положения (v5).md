# Enterprise Technical Specification

# Государственная платформа электронных путевых листов

# Том 1. Общие положения (v5)

## 2. Законодательная и нормативная основа

### 2.1 Цели нормативного обеспечения

Платформа должна обеспечивать юридически значимый электронный
документооборот, прослеживаемость операций, хранение истории изменений,
возможность межведомственного обмена данными и использование электронной
подписи.

### 2.2 Основные принципы

-   Законность обработки данных.
-   Минимизация ручного ввода.
-   Использование государственных реестров как первичного источника
    данных.
-   Единые справочники.
-   Версионирование документов.
-   Неизменяемый журнал аудита.
