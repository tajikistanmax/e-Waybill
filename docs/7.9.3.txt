## ПРИЛОЖЕНИЕ Д. СЛОВАРЬ ТЕРМИНОВ И СОКРАЩЕНИЙ (ГЛОССАРИЙ)

### Д.1. Основные термины

| Термин | Определение |
| :--- | :--- |
| **АДМК** | Автоматизированный диагностический медицинский комплекс — оборудование для проведения медицинских осмотров водителей (алкотестеры, ЭКГ, тонометры) |
| **Аннулирование ЭПЛ** | Отмена электронного путевого листа до момента его закрытия и передачи в ГИС ЭПД |
| **ГИС ЭПД** | Государственная информационная система электронных перевозочных документов — централизованная система учёта электронных перевозочных документов |
| **ГЛОНАСС** | Глобальная навигационная спутниковая система — российская система спутниковой навигации |
| **Диспетчер** | Уполномоченное лицо собственника ТС, создающее и управляющее ЭПЛ |
| **ЕСИА** | Единая система идентификации и аутентификации — портал Госуслуг |
| **Жизненный цикл ЭПЛ** | Полный процесс от создания ЭПЛ до его закрытия, передачи в ГИС ЭПД и архивации |
| **Контролирующие органы** | ГИБДД, Ространснадзор и другие органы, осуществляющие проверку путевых листов |
| **Маршрут** | Путь следования ТС от пункта отправления до пункта назначения (до 10 промежуточных точек) |
| **Механик** | Лицо, ответственное за технический контроль ТС перед выездом и после возвращения |
| **Медицинский работник** | Специалист, проводящий предрейсовые и послерейсовые медицинские осмотры водителей |
| **Одометр** | Прибор для учёта пробега транспортного средства |
| **Оператор ЭДО** | Аккредитованный оператор электронного документооборота, обеспечивающий передачу ЭПЛ в ГИС ЭПД |
| **Платформа ЭПЛ** | Государственная информационная платформа «Электронный путевой лист» |
| **Прицеп** | Транспортное средство, не имеющее собственного двигателя и буксируемое ТС |
| **Путевой лист** | Первичный учётный документ, фиксирующий работу ТС и водителя |
| **СМЭВ** | Система межведомственного электронного взаимодействия |
| **Собственник ТС** | Юридическое лицо или ИП, владеющее транспортным средством |
| **Тахограф** | Устройство для регистрации режима труда и отдыха водителей |
| **Титул ЭПЛ** | Структурная часть электронного путевого листа, содержащая определённый блок сведений (всего 6 титулов) |
| **Транспортное средство (ТС)** | Механическое транспортное средство, используемое для перевозок |
| **УКЭП** | Усиленная квалифицированная электронная подпись — электронная подпись, приравненная к собственноручной |
| **УНЭП** | Усиленная неквалифицированная электронная подпись — электронная подпись, создаваемая с использованием «Госключа» на портале Госуслуг |
| **ЭПЛ** | Электронный путевой лист — путевой лист, оформленный в электронной форме с использованием электронных подписей |

## ПРИЛОЖЕНИЕ Е. МАТРИЦА ОТВЕТСТВЕННОСТИ RACI

### Е.1. Определение уровней ответственности

| Уровень | Описание |
| :--- | :--- |
| **R — Responsible (Исполнитель)** | Кто выполняет работу (действует) |
| **A — Accountable (Ответственный)** | Кто принимает решение, имеет конечную ответственность |
| **C — Consulted (Консультирующий)** | Кто даёт консультации, участвует в обсуждении |
| **I — Informed (Информируемый)** | Кто получает информацию о результате |
