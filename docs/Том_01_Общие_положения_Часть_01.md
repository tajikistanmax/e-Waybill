
# Том 01. Общие положения и концепция
Версия: 0.1 (Часть 1)

Данный том является началом большого технического задания и будет последовательно расширяться.

## 1. Назначение платформы

Государственная информационная система «Электронный путевой лист» предназначена для цифрового сопровождения полного жизненного цикла путевого листа: от подачи заявки и прохождения обязательных проверок до завершения рейса, архивирования и аналитики.

## 2. Цели

- отказ от бумажного документооборота;
- единый государственный реестр путевых листов;
- интеграция с государственными системами;
- юридически значимый электронный документ;
- прозрачность перевозок;
- снижение административной нагрузки.

## 3. Основные принципы

1. Single Source of Truth.
2. API First.
3. Mobile First.
4. Security by Design.
5. Event Driven Architecture.
6. Audit by Default.
7. Cloud Native.
8. Offline First для мобильных приложений.
9. Масштабируемость.
10. Многоязычность.

## 4. Заинтересованные стороны

- Министерство транспорта;
- перевозчики;
- юридические лица;
- ИП;
- водители;
- механики;
- медицинские работники;
- диспетчеры;
- инспекторы;
- налоговые органы;
- МВД/ГАИ;
- таможенные органы;
- операторы DTS.

## 5. Границы автоматизации

Автоматизируются:
- регистрация;
- выдача путевых листов;
- медосмотр;
- техосмотр;
- выпуск ТС;
- контроль рейса;
- закрытие рейса;
- отчеты;
- проверки;
- интеграции;
- архив.
