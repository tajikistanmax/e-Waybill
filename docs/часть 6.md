## РАЗДЕЛ 9. ТРЕБОВАНИЯ К ЭКСПЛУАТАЦИИ

### 9.1. Регламент технического обслуживания

| Параметр | Требование | Детализация |
| :--- | :--- | :--- |
| **Плановые отключения** | Не чаще 1 раза в месяц, не более 2 часов | В ночное время (02:00–04:00 МСК), согласованное с Заказчиком. Уведомление пользователей за 3 рабочих дня. |
| **Обновление ПО** | По утверждённому графику | С предварительным тестированием на тестовом контуре. Откат в течение 30 минут при ошибках. |
| **Резервное копирование** | Ежедневное полное, еженедельное инкрементное | Хранение копий 30 дней. Тестирование восстановления — ежемесячно. |
| **Мониторинг** | Круглосуточный мониторинг доступности, производительности, ошибок | Nagios/Zabbix/Prometheus + Grafana для дашбордов. |
| **Обновление антивирусных баз** | Ежедневно | Автоматическое обновление на всех серверах. |
| **Проверка журналов безопасности** | Ежедневно | Анализ SIEM-логов, выявление подозрительной активности. |
| **Техническое обслуживание оборудования** | Ежеквартально | Проверка состояния серверов, сетевого оборудования, СКЗИ. |

### 9.2. Требования к обучению пользователей

| Параметр | Требование | Детализация |
| :--- | :--- | :--- |
| **Разработка курсов** | Разработка дистанционных курсов обучения для всех категорий пользователей | Видеоуроки, инструкции, тестирование. |
| **Пилотное внедрение** | Внедрение на 5 пилотных организациях | Различных типов: коммерческие перевозчики, перевозчики для собственных нужд, такси, перевозчики алкогольной продукции. |
| **Инструкции** | Разработка инструкций для каждой роли | Диспетчер, медик, механик, водитель, администратор. |
| **Техподдержка** | Обучение технической поддержки (L1, L2) | Навыки работы с системой, решение типовых проблем. |
| **Длительность обучения** | Не менее 2 часов для каждой роли | Теоретическая часть + практическая работа в тестовой среде. |
| **Материалы для обучения** | Предоставление PDF-инструкций и видеоуроков | Доступны в личном кабинете. |

### 9.3. Техническая поддержка

| Параметр | Требование | Детализация |
| :--- | :--- | :--- |
| **График работы** | 24/7 (круглосуточно) | Включая праздничные дни. |
| **Уровни поддержки** | L1 (операторы) | Реакция ≤ 15 минут, решение типовых проблем. |
|  | L2 (инженеры) | Реакция ≤ 30 минут, решение сложных проблем. |
|  | L3 (разработчики) | Реакция ≤ 1 час, решение критических проблем. |
| **SLA** | Время реакции (критические инциденты) | ≤ 30 минут. |
|  | Время решения (критические инциденты) | ≤ 4 часов. |
|  | Время реакции (незначительные инциденты) | ≤ 2 часов. |
| **Каналы связи** | Телефон, Email, Чат (в системе) | Круглосуточно. |
| **Эскалация** | Автоматическая эскалация при превышении времени | Уведомление руководства. |
| **Отчётность по инцидентам** | Еженедельный отчёт | Количество инцидентов, время решения, причины. |

## РАЗДЕЛ 10. ТРЕБОВАНИЯ К ДОКУМЕНТАЦИИ

### 10.1. Состав поставляемой документации

| № | Документ | Описание | Целевая аудитория |
| :--- | :--- | :--- | :--- |
| 1 | **Руководство администратора** | Управление пользователями, справочниками, настройки бизнес-правил, мониторинг, резервное копирование | Администраторы системы |
| 2 | **Руководство пользователя (для каждой роли)** | Инструкции для диспетчера, медика, механика, водителя | Все пользователи |
| 3 | **Руководство по интеграции API** | Описание API-эндпоинтов, форматов запросов/ответов, примеры, коды ошибок | Разработчики, интеграторы |
| 4 | **Руководство по эксплуатации подсистем** | Описание архитектуры, компонентов, настройки серверов, установка СКЗИ | Администраторы, системные инженеры |
| 5 | **Руководство по установке и настройке** | Установка системы на серверах, настройка СКЗИ, настройка интеграций | Системные инженеры |
| 6 | **Руководство пользователя по мобильному приложению** | Инструкция для водителей | Водители |

### 10.2. Требования к документации

| Параметр | Требование |
| :--- | :--- |
| **Форматы предоставления** | Электронные (PDF, DOCX, MD) + Печатные (по требованию Заказчика) |
| **Язык** | Русский |
| **Актуализация** | Обновление документации при каждом изменении системы |
| **Структура** | Оглавление, нумерация страниц, глоссарий |
| **Доступность** | Доступ к документации через личный кабинет |

### 10.3. Содержание руководств

**Руководство администратора:**
- Введение в систему
- Управление пользователями (добавление, блокировка, роли)
- Управление справочниками (ТС, водители, медики, механики)
- Настройка бизнес-правил
- Настройка операторов ЭДО
- Управление резервным копированием
- Мониторинг и анализ логов
- Аудит действий пользователей
- Управление уведомлениями
- Управление системными настройками
- Устранение неполадок

**Руководство пользователя (диспетчер):**
- Вход в систему через ЕСИА
- Создание ЭПЛ (Титул 1)
- Просмотр и управление ЭПЛ
- Аннулирование ЭПЛ
- Формирование отчётов
- Управление справочниками (в рамках своей организации)

**Руководство пользователя (медик):**
- Вход в систему через ЕСИА
- Просмотр назначенных ЭПЛ
- Заполнение Т2 и Т6
- Подписание УКЭП
- Интеграция с АДМК

**Руководство пользователя (механик):**
- Вход в систему через ЕСИА
- Просмотр ТС на выпуск
- Заполнение Т3 (техосмотр)
- Заполнение Т4 и Т5 (одометр)
- Подписание УНЭП/УКЭП

**Руководство пользователя (водитель):**
- Установка мобильного приложения
- Вход через ЕСИА
- Просмотр активных ЭПЛ
- Отображение QR-кода
- Работа офлайн

## ПРИЛОЖЕНИЯ

### ПРИЛОЖЕНИЕ А. ПОЛНЫЕ XML-СХЕМЫ ЭПЛ

**(Согласно Приказу ФНС России от 17.02.2023 № ЕД-7-26/116@)**

#### А.1. Общие положения

XML-схема электронного путевого листа описывает структуру XML-файлов, передаваемых в ГИС ЭПД.

**Состав XML-пакета ЭПЛ:**

| № | Имя файла | Описание | Обязательность |
| :--- | :--- | :--- | :--- |
| 1 | `EPD_PL_Титул1.xml` | Сведения об обстоятельствах и особенностях рейса | Обязательный |
| 2 | `EPD_PL_Титул2.xml` | Сведения о предрейсовом медосмотре | Обязательный |
| 3 | `EPD_PL_Титул3.xml` | Сведения о техническом осмотре ТС | Обязательный |
| 4 | `EPD_PL_Титул4.xml` | Сведения о показаниях одометра при выезде | Обязательный |
| 5 | `EPD_PL_Титул5.xml` | Сведения о показаниях одометра при въезде | Обязательный |
| 6 | `EPD_PL_Титул6.xml` | Сведения о послерейсовом медосмотре | Условно-обязательный |

#### А.2. XML-схема Титула 1 (Обстоятельства рейса)

```xml
<?xml version="1.0" encoding="UTF-8"?>
<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema"
           targetNamespace="http://www.nalog.ru/EPD/PL/Titul1"
           xmlns:tns="http://www.nalog.ru/EPD/PL/Titul1">

  <xs:element name="Титул1">
    <xs:complexType>
      <xs:sequence>
        <!-- Общие сведения о рейсе -->
        <xs:element name="ОбщиеСведения">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="ВидПеревозки" type="tns:ВидПеревозкиТип" minOccurs="1" maxOccurs="1"/>
              <xs:element name="ВидСообщения" type="tns:ВидСообщенияТип" minOccurs="1" maxOccurs="1"/>
              <xs:element name="ДатаНачалаРейса" type="xs:date" minOccurs="1" maxOccurs="1"/>
              <xs:element name="ВремяНачалаРейса" type="xs:time" minOccurs="1" maxOccurs="1"/>
              <xs:element name="СрокДействия" type="xs:date" minOccurs="1" maxOccurs="1"/>
              <xs:element name="ПризнакПослерейсовогоОсмотра" type="xs:boolean" minOccurs="1" maxOccurs="1"/>
            </xs:sequence>
          </xs:complexType>
        </xs:element>

        <!-- Сведения о собственнике ТС -->
        <xs:element name="СобственникТС" minOccurs="1" maxOccurs="1">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="ИНН" type="tns:ИННТип" minOccurs="0" maxOccurs="1"/>
              <xs:element name="ОГРН" type="tns:ОГРНТип" minOccurs="0" maxOccurs="1"/>
              <xs:element name="Наименование" type="xs:string" minOccurs="1" maxOccurs="1"/>
              <xs:element name="КПП" type="tns:КППТип" minOccurs="0" maxOccurs="1"/>
            </xs:sequence>
          </xs:complexType>
        </xs:element>

        <!-- Сведения о ТС -->
        <xs:element name="ТранспортноеСредство" minOccurs="1" maxOccurs="1">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="Госномер" type="tns:ГосномерТип" minOccurs="1" maxOccurs="1"/>
              <xs:element name="VIN" type="tns:VINТип" minOccurs="1" maxOccurs="1"/>
              <xs:element name="Марка" type="xs:string" minOccurs="1" maxOccurs="1"/>
              <xs:element name="Модель" type="xs:string" minOccurs="1" maxOccurs="1"/>
              <xs:element name="ГодВыпуска" type="xs:gYear" minOccurs="0" maxOccurs="1"/>
            </xs:sequence>
          </xs:complexType>
        </xs:element>

        <!-- Сведения о прицепе (опционально) -->
        <xs:element name="Прицеп" minOccurs="0" maxOccurs="1">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="Госномер" type="tns:ГосномерТип" minOccurs="1" maxOccurs="1"/>
              <xs:element name="VIN" type="tns:VINТип" minOccurs="0" maxOccurs="1"/>
              <xs:element name="Марка" type="xs:string" minOccurs="0" maxOccurs="1"/>
            </xs:sequence>
          </xs:complexType>
        </xs:element>

        <!-- Сведения о водителе -->
        <xs:element name="Водитель" minOccurs="1" maxOccurs="5">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="ФИО" type="tns:ФИОТип" minOccurs="1" maxOccurs="1"/>
              <xs:element name="НомерПрав" type="tns:НомерПравТип" minOccurs="1" maxOccurs="1"/>
              <xs:element name="Стаж" type="xs:integer" minOccurs="0" maxOccurs="1"/>
              <xs:element name="СНИЛС" type="tns:СНИЛСТип" minOccurs="0" maxOccurs="1"/>
            </xs:sequence>
          </xs:complexType>
        </xs:element>

        <!-- Маршрут -->
        <xs:element name="Маршрут" minOccurs="1" maxOccurs="1">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="Пункт" type="tns:ПунктТип" minOccurs="2" maxOccurs="10"/>
            </xs:sequence>
          </xs:complexType>
        </xs:element>
      </xs:sequence>
    </xs:complexType>
  </xs:element>

  <!-- Определение типов данных -->
  <xs:simpleType name="ВидПеревозкиТип">
    <xs:restriction base="xs:string">
      <xs:enumeration value="КОММЕРЧЕСКАЯ"/>
      <xs:enumeration value="СОБСТВЕННЫЕ_НУЖДЫ"/>
    </xs:restriction>
  </xs:simpleType>

  <xs:simpleType name="ВидСообщенияТип">
    <xs:restriction base="xs:string">
      <xs:enumeration value="ГОРОДСКОЕ"/>
      <xs:enumeration value="ПРИГОРОДНОЕ"/>
      <xs:enumeration value="МЕЖДУГОРОДНОЕ"/>
      <xs:enumeration value="МЕЖДУНАРОДНОЕ"/>
    </xs:restriction>
  </xs:simpleType>

  <xs:simpleType name="ИННТип">
    <xs:restriction base="xs:string">
      <xs:pattern value="[0-9]{10}|[0-9]{12}"/>
    </xs:restriction>
  </xs:simpleType>

  <xs:simpleType name="ОГРНТип">
    <xs:restriction base="xs:string">
      <xs:pattern value="[0-9]{13}"/>
    </xs:restriction>
  </xs:simpleType>

  <xs:simpleType name="КППТип">
    <xs:restriction base="xs:string">
      <xs:pattern value="[0-9]{9}"/>
    </xs:restriction>
  </xs:simpleType>

  <xs:simpleType name="ГосномерТип">
    <xs:restriction base="xs:string">
      <xs:pattern value="[A-ZА-Я]{1}[0-9]{3}[A-ZА-Я]{2}[0-9]{2,3}"/>
    </xs:restriction>
  </xs:simpleType>

  <xs:simpleType name="VINТип">
    <xs:restriction base="xs:string">
      <xs:pattern value="[A-HJ-NPR-Z0-9]{17}"/>
    </xs:restriction>
  </xs:simpleType>

  <xs:simpleType name="ФИОТип">
    <xs:restriction base="xs:string">
      <xs:minLength value="5"/>
      <xs:maxLength value="100"/>
    </xs:restriction>
  </xs:simpleType>

  <xs:simpleType name="НомерПравТип">
    <xs:restriction base="xs:string">
      <xs:pattern value="[0-9]{2}[A-ZА-Я]{2}[0-9]{6}"/>
    </xs:restriction>
  </xs:simpleType>

  <xs:simpleType name="СНИЛСТип">
    <xs:restriction base="xs:string">
      <xs:pattern value="[0-9]{3}-[0-9]{3}-[0-9]{3} [0-9]{2}"/>
    </xs:restriction>
  </xs:simpleType>

  <xs:complexType name="ПунктТип">
    <xs:sequence>
      <xs:element name="Адрес" type="xs:string" minOccurs="1" maxOccurs="1"/>
      <xs:element name="Широта" type="xs:decimal" minOccurs="0" maxOccurs="1"/>
      <xs:element name="Долгота" type="xs:decimal" minOccurs="0" maxOccurs="1"/>
    </xs:sequence>
  </xs:complexType>

</xs:schema>
