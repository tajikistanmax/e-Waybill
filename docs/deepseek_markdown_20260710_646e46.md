## 1. ОБЩИЕ СВЕДЕНИЯ

**1.1. Наименование**  
Государственная информационная платформа «Электронный путевой лист» (Платформа ЭПЛ).

**1.2. Заказчик**

**1.3. Основания**

## 3. БИЗНЕС-ПРОЦЕССЫ

**3.1. Как сейчас (бумага)**  
8 этапов: диспетчер → медик → механик → водитель → архив.  
Минусы: потери, ошибки, нет интеграции, штрафы.

**3.2. Как будет (ЭПЛ)**  
Создание Т1 → Т2 (медик + УКЭП) → Т3 (механик) → Т4 (одометр) → QR → рейс → Т5 (одометр) → Т6 (если нужно) → закрытие → XML → ГИС ЭПД → архив.

## 5. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

### 5.1. Титулы ЭПЛ

**Т1 — Обстоятельства рейса**  
Поля: вид перевозки, вид сообщения, дата/время, срок, собственник, ТС, водитель, прицеп, маршрут (до 10 точек), признак послерейсового осмотра.  
Права: только диспетчер.

**Т2 — Предрейсовый медосмотр**  
Поля: дата/время, результат (годен/не годен), медработник (ФИО, СНИЛС), лицензия.  
Подпись: УКЭП.

**Т3 — Техосмотр**  
Поля: дата/время, результат, чек-лист (10 пунктов), механик.  
Подпись: УНЭП или УКЭП.

**Т4 — Одометр на выезде**  
Поля: дата/время, показания, кто зафиксировал.  
После подписи → генерация QR-кода.

**Т5 — Одометр на въезде**  
Поля: дата/время, показания (≥ Т4), кто зафиксировал.

**Т6 — Послерейсовый медосмотр**  
Условно-обязательный (если признак в Т1 = «Да»).  
Подпись: УКЭП.

### 5.2. Мобильное приложение водителя
- iOS 14+, Android 10+
- Вход через ЕСИА
- QR-код (обновление 60 с)
- Офлайн-режим
- Push-уведомления

### 5.3. Личный кабинет медработника
- Список ЭПЛ на осмотр
- Заполнение Т2 и Т6
- Подпись УКЭП
- История осмотров

### 5.4. Личный кабинет механика
- Список ТС на выпуск
- Заполнение Т3, Т4, Т5
- Чек-лист
- Подпись УНЭП / УКЭП

### 5.5. Администрирование
- Пользователи (роли: диспетчер, медик, механик, администратор)
- Справочники (ТС, водители, медики, механики)
- Импорт / экспорт (XLSX, CSV)
- Аудит и логи
- Мониторинг статусов ЭПЛ

### 5.6. Отчётность
- Отчёты по ЭПЛ (день / месяц / квартал)
- Экспорт: XML, XLSX, PDF
- Статистика нарушений
