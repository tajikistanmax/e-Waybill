# 2026-09-24 — Офлайн-карта Таджикистана в GPS-мониторинге

## Что изменилось
- `apps/web/public/map/tajikistan.pmtiles` (45 МБ, новый): векторная карта Таджикистана из
  OpenStreetMap — выгрузка Protomaps Basemap (сборка 24.09.2026) по границам РТ с запасом
  (67,2–75,3° в. д., 36,5–41,2° с. ш.), уровни 0–12.
- `apps/web/app/monitoring/LeafletMap.tsx`: подложка рисуется из этого файла библиотекой
  `protomaps-leaflet` (новая зависимость `apps/web/package.json`, `package-lock.json`); если
  файла нет — прежний контур границы; внешний тайл-сервер по-прежнему задаётся
  `NEXT_PUBLIC_MAP_TILES_URL`.
- `packages/shared/lib/i18n.tsx`: подсказка под картой; `.gitattributes`: `*.pmtiles binary`.

## Как было ДО
Без интернета (закрытый контур) вместо карты был однотонный фон с упрощённым контуром границы
РТ: ни дорог, ни городов, ни рек — точки машин «в пустоте» (замечание владельца 24.09 со
скриншотом /monitoring: «карту Таджикистана я не вижу, тут только линии»).

## Как стало
Полноценная карта без интернета: рельеф и растительность, реки и водохранилища, города и
районы с подписями на русском, дороги всех классов, в городах — улицы с названиями (при
приближении данные уровня 12 дорисовываются крупнее, до уровня 17). Внешних запросов нет
(проверено в браузере), подпись © OpenStreetMap — как требует лицензия ODbL. Та же карта — в
кабинете водителя (карточка рейса).

## Почему
Владелец 24.09.2026: «скачай офлайн что-то, чтобы серьёзно всё выглядело».

## Кто решил
Владелец — задача; решение (векторная выгрузка OSM одним файлом, уровни 0–12) — разработчик
(Claude). Спорное: уровень 13 дал бы файл 86 МБ, 14 — 163 МБ (GitHub принимает файлы до
100 МБ); уровня 12 хватает для улиц — векторные данные при приближении не «размываются».
Обновление карты — повторная выгрузка той же командой (см. «Как»), раз в полгода-год.

## Как
```
docker run --rm -v <папка>:/data protomaps/go-pmtiles extract \
  https://build.protomaps.com/<ГГГГММДД>.pmtiles /data/tajikistan.pmtiles \
  --bbox=67.2,36.5,75.3,41.2 --maxzoom=12
```
Файл отдаётся платформой (Next.js из `public/`) запросами по диапазону байтов — проверено:
`Range: bytes=0-99` → 206 и напрямую (:3000), и через HTTPS-прокси. Перед подключением
подложки компонент проверяет наличие файла (HEAD) — без файла остаётся контур, а не пустой экран.

## Как проверено
`tsc --noEmit` — без ошибок; web пересобран; браузер: /monitoring на уровне страны и улиц
Душанбе (скриншоты), внешних запросов 0, ошибок консоли — только 404 незаданных логотипа и фона
бренда (так задумано).
