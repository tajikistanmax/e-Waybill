# 2026-09-26 — Отчёты: итоги по депо и видам маршрутов, колонки legacy, журнал механика, печать с титулом

## Что изменилось
- **Строка отчёта** (`calc/report/ReportRow.java`) — новые колонки:
  - план рейсов («давр нақша»);
  - число разных ТС («миқдори автомобил»);
  - время по заказу («вақти фармоишӣ»);
  - вторая подпись группы: гаражный №, № маршрута, рамз марки или табель;
  - группа для промежуточного итога.
- **Отчёт** (`calc/report/WaybillReport.java`) — промежуточные итоги `subtotals`.
- **Сервис отчётов** (`service/WaybillReportService.java`):
  - «По ТС» у троллейбусов — итоги по депо (депо = первая цифра гаражного номера, как в legacy `BusCalc::type1`, бланк ebus). Если в снимке листа гаражного номера нет — берётся из реестра ТС, один запрос на организацию;
  - «По маршрутам» — № и вид маршрута из справочника, итоги по видам маршрутов (`BusCalc::type2`);
  - «По маркам» — рамз марки;
  - «По водителям» и «Заработок водителей» — табель, время по заказу из рабочих дней.
- **Справочник** (`client/MasterDataClient.listRouteTypes`) — виды маршрутов.
- **Журнал механика** (`service/InspectionJournalService.java`) — добавлены:
  - выезд (Т4);
  - возврат (Т5);
  - одометр возврата;
  - техсостояние при возврате — как в legacy «Дафтари қайди механик»: «Баромад / Даромад ба таваққуфгоҳ».
- **Excel** (`print/ReportXlsxWriter.java`) — новые колонки, строки промежуточных итогов и колонки возврата в журнале механика.
- **Веб:**
  - `reports/ReportsView.tsx`: новые колонки по типу разреза; строки «Итого: Депо N / вид маршрута»; кнопка «Печать» — титул как в отчётах «Роҳхат» (lang/tj/report.php), все строки без постраничности, фильтры и меню скрыты;
  - там же исправлена гонка запросов: опоздавший ответ старого запроса больше не затирает новый отчёт;
  - `reports/JournalsTab.tsx`: колонки возврата в журнале механика;
  - `globals.css`: стили печати;
  - `api.ts`, i18n RU/TJ.
- **Тесты:**
  - `WaybillReportServiceTest` +1 — депо и число ТС;
  - e2e `reports-per-waybill.spec.ts` +1 — колонки и титул.

## Как было ДО
- Итогов по депо и по видам маршрутов не было.
- Колонок legacy не было: «Миқдори автомобил», «давр нақша», «Рақами / Намуди хатсайр», «Рамзи тамға», «Рақами таб.», «Вақти фармоишӣ».
- В журнале механика — только выезд.
- Печатать отчёт можно было только выгрузкой в Excel.
- При смене разреза, пока шёл медленный запрос, на экране оставались старые строки под новыми заголовками. Иногда опоздавший старый ответ затирал новый отчёт.
