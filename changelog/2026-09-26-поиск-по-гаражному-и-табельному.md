# 2026-09-26 — Мастер ПЛ: поиск ТС по номеру стоянки, водителя по табельному номеру

## Что изменилось
- `master-data-service/.../repository/VehicleRepository.java` — `searchByOrg/searchByOrgs` ищут по госномеру **и номеру стоянки** (гаражному).
- `master-data-service/.../repository/DriverRepository.java` — `searchByOrg/searchByOrgs` ищут по ИНН, Ф.И.О **и табельному номеру**.
