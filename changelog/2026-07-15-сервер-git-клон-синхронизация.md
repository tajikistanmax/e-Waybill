# 2026-07-15 — Сервер 10.10.29.70: копия проекта превращена в git-клон (синхронизация с GitHub)

## Что изменилось
Каталог `~/e-rohkhat` на стенде 10.10.29.70 стал полноценным git-клоном репозитория
`https://github.com/tajikistanmax/e-Waybill.git` (ветка `main`, upstream настроен).
Плюс в этом файле-журнале исправлен устаревший хэш коммита бланка 5Б-БМ
(в записи от 2026-07-14 был указан `b5b1ee8`, фактический хэш в истории — `a3ab66c`).

## Как было ДО
На сервере лежала «мёртвая» копия исходников без `.git` (загружена вручную при первом
деплое). Команда деплоя из CLAUDE.md (`cd ~/e-rohkhat && git pull`) не работала —
`fatal: not a git repository`. Синхронизировать сервер с GitHub можно было только
повторной ручной загрузкой файлов; сверить, какая версия развёрнута, было нельзя.
Фактически на сервере лежал код коммита `a3ab66c` (проверено `git diff --ignore-cr-at-eol`:
отличие только в build-артефакте `tsconfig.tsbuildinfo` и переводах строк CRLF).

## Как стало
`~/e-rohkhat` — git-клон: `git init` → `remote add origin` → `fetch` → ветка `main`
с upstream `origin/main`. Старое дерево (CRLF-варианты файлов) сохранено в
`git stash` («снимок дерева до синхронизации…»), рабочее дерево приведено к
`origin/main` (`e19d706`). `git status` чистый; `infra/.env` с секретами не тронут
(untracked, в `.gitignore`). Все 8 контейнеров работают, web и Keycloak отвечают 200.
Теперь деплой по документации работает: `git pull` → `docker compose ... up -d --build`.

## Почему
Правило проекта: изменения должны синхронно попадать на GitHub и на сервер, и всегда
должно быть видно, какая версия где развёрнута. Без git на сервере это правило
невыполнимо и нет пути отката.

## Кто решил
Джамшед (владелец) — задача «изменения должны синхронно обновляться на GitHub и на
сервер». Техническое решение (git-клон на месте, без пересоздания каталога, чтобы не
трогать работающие контейнеры и `.env`) — агент Claude. Вариант `git stash` вместо
`reset --hard` выбран сознательно: старое состояние дерева сохранено и восстановимо.

## Коммиты
- docs(changelog): сервер 10.10.29.70 как git-клон + исправлен хэш коммита 5Б-БМ
  (запись описывает сама себя — точный хэш см. `git log --oneline -1 -- changelog/2026-07-15*`)

## Как откатить
- Запись журнала: `git revert <hash>` → `git push origin main`.
- Состояние сервера: вернуть старое дерево — `ssh behruz@10.10.29.70`,
  `cd ~/e-rohkhat && git stash pop` (вернёт CRLF-копию поверх клона);
  полностью убрать git — `rm -rf ~/e-rohkhat/.git` (файлы проекта не затрагивает).
  Контейнеры от отката не зависят (собраны из образов).
