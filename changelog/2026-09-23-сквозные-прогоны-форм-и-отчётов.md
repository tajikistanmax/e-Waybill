# 2026-09-23 — Повторяемые сквозные прогоны: все формы путевых листов и все отчёты

## Что изменилось
Добавлены три файла в `scripts/`:
- `e2e-all-forms.ps1` — живой прогон КАЖДОЙ формы (Т(1-АД) автобус, троллейбус, 1-А, 3-С легковой,
  3-С такси, 2-Б, 5Б-БМ, 4М-БМ, спецтехника) по всему циклу под своими ролями: выписка
  диспетчером → Т1 → врач Т2 → механик Т3 (одометр) → оплата бухгалтером (номер) → приём водителем в
  мобильном кабинете / выдача → топливо → Т4 выезд → рабочий день (рейсы, выручка) / накладная /
  СМР → расходы → Т5 возврат (транспортная работа, ездки, прибытие, пассажиры, моточасы) →
  закрытие без Т6 = 409 → Т6 → повторный Т6 = 409 → закрытие → одометр ТС в справочнике → расчёт
  нормы и полный расчёт → касса (3-С) → печать PDF (бланк, приложение к накладной, СМР) → QR →
  публичная проверка `/verify` без входа → история и титулы Т1…Т6 (у Т4/Т5 — Ф.И.О.).
  Негативные ветки: отключённый тип, недопуск врачом → замена водителя, недопуск механиком,
  второй лист на занятое ТС/водителя (409), блокировка инспектором, отказ диспетчеру в
  разблокировке (403), разблокировка Минтрансом, аннулирование, просроченный техосмотр (422),
  неверный дозвол (422), чужая организация и чужая роль (403).
- `e2e-fixture.json` — тестовый парк организации 025680800 (организация, сотрудники под
  демо-логинами, маршруты, по ТС и водителю на каждую форму и на негативные ветки). Только
  добавление/обновление, повторный запуск безопасен.
- `e2e-reports.ps1` — все отчёты, журналы и выгрузки службы путевых листов за период под ролями,
  которые ими пользуются (бухгалтер, диспетчер, компания, инспектор, аналитик, админ), с проверкой
  XLSX-сигнатуры и временем; `-ArchiveOrg` — отчёты по архиву реальной организации.

## Как было ДО
Сквозные проверки жили в разовых командах (`smoke-test.ps1` — одна форма, вход ещё через Keycloak);
повторить проверку всех форм и отчётов перед показом было нечем.

## Как стало
Одна команда — полный прогон: `powershell -ExecutionPolicy Bypass -File scripts\e2e-all-forms.ps1`
(≈15 с, 324 проверки) и `scripts\e2e-reports.ps1 [-From … -To … -ArchiveOrg 040000796]`
(70–86 проверок). Код выхода — число проваленных проверок; итог — JSON в `%TEMP%\ewb-e2e*`.

## Почему
Перед демонстрацией 24.09 нужно быстро убедиться, что все формы и отчёты работают после любых
пересборок; прогоны уже нашли 8 ошибок (см. журналы 23.09 «служебная учётная запись», «Т6 и
закрытие», «отчёты»).

## Кто решил
Владелец 23.09.2026: «доведи платформу до запуска к демонстрации»; руководитель поручил сохранить
повторяемый прогон в `scripts/`. Реализовал агент Claude (блок «путевые листы, расчёты, печать, отчёты»).

## Как
PowerShell 5.1, только ASCII в `.ps1` (кириллица — в JSON); вход `POST /api/v1/auth/token`,
пароли — `scripts/demo-credentials.ps1`; HTTP через `HttpWebRequest` (коды 4xx/5xx без исключений).

## Как проверено
`e2e-all-forms.ps1` — 324 из 324; `e2e-reports.ps1` за 24.08–23.09 — 70 из 70; за июль 2026 с
`-ArchiveOrg 040000796` — 86 из 86 (сводный региональный по пассажирам ≈30 с — помечен SLOW).
