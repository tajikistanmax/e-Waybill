# 2026-10-21 — Отключён второй фактор входа (2FA)

## Что изменилось
Вход в платформу больше не спрашивает код из приложения-аутентификатора: все учётные записи,
включая суперадмина, входят только по логину и паролю. Второй фактор не удалён из кода, а
выключен переключателем `epd.auth.second-factor.enabled` (переменная окружения
`AUTH_SECOND_FACTOR`, по умолчанию `false`).

## Как было ДО
У учётных записей с признаком «2FA обязательна» (`admin`, `inspector`, `analyst` и новые
SYSTEM_ADMIN/инспекторы/аналитики) или с уже подключённым аутентификатором после верного
пароля открывалась страница «Подтверждение входа»: подключить приложение по QR-коду и ввести
6-значный код. Без кода сессия не выдавалась.

## Как стало
После верного пароля сессия выдаётся сразу, страница кода не показывается никому. Признаки
`totp_required` / `totp_secret` в базе не тронуты: если вернуть `AUTH_SECOND_FACTOR=true`,
всё работает как раньше, подключённые аутентификаторы снова будут спрашиваться.
Переключатель «2FA обязательна» на странице «Пользователи» при выключенной 2FA ни на что не
влияет.

## Почему
Владелец не мог войти суперадмином на локальном стенде: требовалось подключать телефонное
приложение. Решено отказаться от второго фактора во всей платформе.

## Кто решил
Владелец платформы поставил задачу («убери это») и на уточняющий вопрос выбрал вариант
«во всей платформе, включая боевой» (вместо отключения только у локальной учётки).
Реализовал агент Claude. Компромисс: снижается защита учёток с широкими правами (находка 27
AUDIT.md, ИБ-требование 2FA для admin/inspector/analyst) — поэтому выключено переключателем,
а не удалено, чтобы вернуть одной переменной.

## Затронутые файлы
- `apps/backend/master-data-service/src/main/java/tj/mintrans/epd/masterdata/auth/AuthService.java` — флаг `secondFactorEnabled`; второй шаг входа только при включённом флаге.
- `apps/backend/master-data-service/src/main/resources/application.yml` — `epd.auth.second-factor.enabled: ${AUTH_SECOND_FACTOR:false}`.
- `apps/backend/master-data-service/src/test/java/tj/mintrans/epd/masterdata/auth/AuthServiceTest.java` — старые тесты 2FA гоняются с включённым флагом; новый тест «выключен → вход по паролю».
- `apps/web/e2e/second-factor.spec.ts` — e2e 2FA пропускается, пока не задан `E2E_SECOND_FACTOR=1`.
- `infra/docker-compose.prod.yml` — `AUTH_SECOND_FACTOR` передаётся в master-data (по умолчанию `false`).
- `infra/env.example` — описание переменной.

Проверка: `gradle :master-data-service:test --tests "tj.mintrans.epd.masterdata.auth.*"` — зелёные;
локальный стенд пересобран, master-data healthy.
