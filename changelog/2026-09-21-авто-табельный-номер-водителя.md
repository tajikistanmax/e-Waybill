# 2026-09-21 — Водители: авто-присвоение табельного номера max+1 по организации (legacy `DriverObserver`, MIGRATION.md §11.7)

## Что изменилось
- Новый компонент master-data `DriverTabNumbers`: `resolve(запрошенный, существующий, организация)` — заданный номер
  → как есть (обрезка пробелов); иначе прежний номер водителя; иначе `max(числовых номеров организации) + 1`
  (первый водитель — «1»). Нечисловые/пустые номера при поиске максимума игнорируются.
- `DriverRepository.findTabNumbersByOrganization(org)` — JPQL-выборка номеров организации.
- Применяется в обоих путях создания/обновления водителя: `POST /api/v1/drivers` (`DriverController.upsert`) и
  `POST /api/v1/sync/driver` (`SyncController.syncDriver`).
- Тест `DriverTabNumbersTest` (4): max+1 с мусорными номерами; первый — «1»; явный номер сохраняется; обновление без
  номера сохраняет прежний / выдаёт новый при отсутствии.

## Как было ДО
В legacy `App\Observers\DriverObserver`: при создании `number = max(number where company_id) + 1` (безусловно), при
обновлении — то же, если номер пуст. В e-Waybill `tabNumber` вводился только вручную (или приходил из sync); при
upsert без поля номер затирался в `null`.

## Как стало
Водитель без табельного номера получает следующий по организации автоматически; ранее присвоенный номер при
обновлении без поля не теряется.

## Осознанные отличия от legacy (в Javadoc компонента)
- Legacy при создании перезаписывал номер max+1 даже если он был введён в форме — это баг/квирк, не переносим:
  явно заданный номер сохраняется.
- Legacy при обновлении с пустым номером выдавал новый max+1; у нас отсутствие поля в запросе = «оставить прежний»
  (upsert-API), новый выдаётся только если номера ещё нет.
- Гонка двух одновременных созданий даёт одинаковый номер — как в оригинале (уникальности в БД нет; при
  необходимости — отдельное решение).

## Почему
MIGRATION.md 11.7 — служебный гэп паритета (Шаг 1 инвентаризации), фактический номер нужен на бланках/в отчётах.

## Кто решил
Агент Claude по промпту Шага 2. Отличия от legacy — по правилу «баги не переносим, документируем».
