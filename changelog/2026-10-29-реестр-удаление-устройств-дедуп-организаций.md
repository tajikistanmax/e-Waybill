# 2026-10-29 — Реестр: убран неиспользуемый раздел «Устройства», дедуп вкладки «Организации», фикс счётчика

## Что изменилось
Три связанные правки раздела «Реестр» (`/registry/*`), найденные при визуальном проходе
26.10.2026:
1. Раздел «Мобильные устройства» убран целиком: страница, API, бэкенд.
2. Для `SYSTEM_ADMIN` вкладка «Организации» в реестре скрыта (дублировала «Компания»).
3. Расходящийся счётчик организаций на карточке раздела (592 vs 472) — исправлен.
4. Панель «Активность за период» в реестре ТС/водителей переставлена выше списка.

## Как было ДО
1. `/registry/devices` показывала реестр авторизованных мобильных устройств водителей
   (перенос legacy «Телефонҳо»). Признаков использования в продукте не найдено — отдельный
   CRUD без реальных ссылок на него из остального функционала.
2. У `SYSTEM_ADMIN` вкладка «Организации» в реестре (read-only) дублировала полноценный
   CRUD в разделе «Компания» (`/company`) — тот же список организаций вторым пунктом меню.
3. Карточка «Организации» в шапке реестра показывала `rows.length` от
   `/organizations/counts` — а этот эндпоинт возвращает только организации, у которых
   есть хотя бы один ТС/водитель/сотрудник, то есть список короче полного реестра
   (592 реальных организаций, но карточка показывала 472).
4. `ActivityPanel` (фильтр по активности — legacy `active_trans`/`inactive_trans`)
   рисовалась НИЖЕ основного списка ТС/водителей — пользователю нужно было пролистать
   весь реестр, чтобы увидеть и применить фильтр.

## Как стало
1. Удалены: `MobileDeviceController`, `MobileDeviceRepository`, домен `MobileDevice`
   (backend), страница `/registry/devices`, тип `MobileDevice` и методы
   `md.mobileDevices/saveMobileDevice/deleteMobileDevice` (frontend), i18n-ключи
   `nav.devices`/`dev.*`. Эндпоинт `/api/v1/mobile-devices` (V64) больше не существует.
2. `RegistryLayout`: для `SYSTEM_ADMIN` вкладка `organizations` отфильтрована из списка;
   прямой заход по ссылке/закладке на `/registry/organizations` редиректит на `/company`.
3. Счётчик «Организации» теперь получается отдельным вызовом `md.organizations()`
   (`rows.length` от полного списка), а не от `/organizations/counts`.
4. `ActivityPanel` перенесена выше `<div className="card">` со списком.

## Почему
Прямое указание владельца при визуальном проходе 26.10.2026: убрать неиспользуемое,
убрать дублирование меню у сисадмина, исправить расходящиеся цифры, поднять фильтр
активности над списком.

## Кто решил
