# 2026-10-30 — Региональный скоуп аналитика Минтранса (F10)

## Что изменилось
Учётке `MINTRANS_ANALYST` теперь можно назначить регион (1–7). С назначенным
регионом реестр организаций/ТС/водителей/сотрудников принудительно сужается
до него. Без региона — прежнее поведение (видит всю страну).

## Как было ДО
Сверка 25.09.2026 (F10): «Аналитик Минтранса не видит реестр организаций;
региональный скоуп аналитика отсутствует». Первая половина (видимость
реестра) закрыта 26.09.2026. Вторая («региональный скоуп») осталась
нерешённой («❓») — аналитик видел весь реестр по всей стране без
возможности ограничить область одним регионом.

## Как стало
- Миграция V91: `app_user.region_id` (SMALLINT, nullable, `NULL` по
  умолчанию — ничего не меняется для существующих учёток).
- `TokenIssuer` добавляет claim `region_id` в токен, только если задан.
- `RegistryQuery.organizationScope()` (общий метод для реестров ТС/
  водителей/сотрудников — `VehicleController`/`DriverController`/
  `EmployeeController`) принудительно пересекает область с регионом
  аналитика ДО остальных фильтров: аналитик не может расширить себе
  область, передав другой `regionId` в запросе.
- `OrganizationController.list()` — тот же принцип для реестра организаций
  (свой путь запроса, не завязан на `RegistryQuery`).
- `PlatformUserController`: `regionId` в `CreateRequest`/`RoleRequest`,
  валидация (1–7), применяется только к роли `MINTRANS_ANALYST` — для
  остальных ролей всегда `null`, даже если что-то передано по ошибке UI.
- UI «Пользователи платформы» (`/company/access/users`): выбор региона
  появляется в форме создания и в строке смены роли, только когда выбрана
  роль «Аналитик Минтранса»; регион показан в столбце «Организация» списка
  (вместо «платформа», если регион назначен).

## Почему
Прямое решение владельца 30.10.2026 после перепроверки нерешённых пунктов
сверки 25.09 («у нас есть регионы, сделай»).

## Что сознательно НЕ тронуто
Отчёт «Умумӣ» (`RegionalReportService`, межрегиональная сводка Минтранса) —
не ограничен регионом аналитика: этот отчёт по смыслу сравнивает регионы
между собой, сужение одного аналитика до «своего» региона убрало бы саму
суть инструмента. Если нужно и его ограничить — отдельное решение владельца.

## Кто решил
Находка сверки 25.09.2026 (F10); решение и подтверждение — владелец
30.10.2026; реализовал агент Claude.
