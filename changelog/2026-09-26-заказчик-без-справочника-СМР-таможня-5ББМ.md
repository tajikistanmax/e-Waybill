# 2026-09-26 — 2-Б и СМР без пустого справочника клиентов; таможню подтверждает только таможня; обязательные поля 5Б-БМ в мастере

## Что изменилось
- `apps/web/app/waybills/new/page.tsx` — мастер путевого листа:
  - 2-Б: если заказчика нет в справочнике клиентов, его можно ввести по наименованию. Сохраняется `clientName` без `clientId`.
  - 5Б-БМ: города погрузки и разгрузки и номер ББА отмечены обязательными; без них кнопка перехода к подтверждению неактивна.
- `apps/web/app/waybills/[id]/Consignment.tsx` — накладная/СМР: отправитель, получатель, экспедитор и груз тоже можно ввести по наименованию, если их нет в справочнике.
- `apps/backend/.../web/WaybillController.java` — `POST /waybills/{id}/consignment`: поля `customsOfficerName` и `customsConfirmedAt` из запроса перевозчика больше не записываются.
- Тест `WaybillControllerSecurityTest.dispatcherCannotConfirmCustoms`.

## Как было ДО
- **2-Б.** «Заказчик» с 25.09 обязателен и выбирается только из справочника клиентов организации.
  - У организаций справочник клиентов пуст: архивные клиенты не перенесены (сверка, F12).
  - Итог: **диспетчер не мог выписать ни одного листа 2-Б через интерфейс** — кнопка «Далее» не активировалась.
- **СМР 5Б-БМ.** Отправителя и получателя тоже можно было только выбрать из того же пустого справочника.
- **Таможня.** Диспетчер мог отправить в `/consignment` поля таможенника и даты подтверждения — то есть «подтвердить вывоз за таможню» (сверка 25.09, C3). В интерфейсе этих полей нет с 24.09, но API их принимал.
- **5Б-БМ в мастере.** Города и номер ББА не отмечались обязательными. Сервер их требует (legacy `StoreWaybill5bbmRequest`), и диспетчер узнавал об этом только по ошибке 422 после заполнения всего мастера.

## Как стало
- Поиск контрагента или груза показывает последней строкой «Нет в справочнике — записать как введено».
  - Сохраняется снимок наименования, как и у выбранных из справочника (печать берёт имя из снимка).
  - Выбор из справочника работает как прежде и сохраняет id.
- Подтверждение СМР пишет только таможня: `POST /api/v1/consignments/{id}/customs-confirm`, роль таможенника, как legacy `validatecmr`.
- Мастер 5Б-БМ требует то же, что сервер.

## Почему
- Сверка 25.09: C3 (подтверждение за таможню), C4 (обязательные поля СМР/5Б-БМ).
- Блокер выписки 2-Б найден при проверке борхатов 26.09: справочник клиентов организации фикстуры пуст — таким он будет и на боевом стенде до повторной загрузки архива.

## Кто решил
- Задача — владелец («сделай нашу платформу к продакшену»).
- В legacy заказчик и стороны — только из справочника. Ввод по наименованию — решение исполнителя: иначе до переноса клиентов 2-Б не выписать.
- Если нужен строгий legacy-вариант — после загрузки клиентов строку «записать как введено» можно убрать отдельным коммитом.
- Ограничение: кабинеты грузоотправителя и экспедитора находят накладную по id клиента. Сторона, введённая по наименованию, свою накладную в кабинете не увидит.
