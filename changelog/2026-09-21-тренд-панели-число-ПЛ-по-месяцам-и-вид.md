# 2026-09-21 — Тренд панели: число выписанных ПЛ по месяцам и выбор вида (автобус / троллейбус), legacy `dashboard/ebus` (MIGRATION.md §6.8)

## Что изменилось
- `GET /api/v1/reports/passenger-volume-trend?months=&type=` — каждая точка теперь несёт `waybills` (число ПЛ,
  выписанных в месяце, все статусы — как legacy `COUNT … GROUP BY MONTH(created_at)`), ответ — ещё `types`.
  Необязательный `type=WB_BUS|WB_TROLLEYBUS` сужает тренд до одного вида (legacy панель — только троллейбус);
  другой вид → 422.
- `WaybillRepository.countByMonth[ForOrganizations]` — группировка по году/месяцу в БД (JPQL `extract`), а не проход
  по строкам: у платформенной роли в 7 месяцах после Ф5 сотни тысяч ПЛ. Оборот по-прежнему считается потоком по
  завершённым ПЛ (`WaybillPeriodScan.forEachCompleted`).
- `RegionalReportService.passengerVolumeTrend(months, types)`; прежний `passengerVolumeTrend(months)` = оба вида.
- Web `/dashboard`: график «Пассажирооборот» стал комбинированным — столбцы «ПЛ, шт.» (правая ось, цвет legacy
  `rgb(66,186,150)`) + линия оборота; в заголовке карточки выбор «Автобус + троллейбус / Автобус / Троллейбус».
  `api.ts`: `passengerVolumeTrend(months, type?)`, тип `PassengerVolumeTrend` (+`waybills`, `types`). i18n ru/tj.
- Тест `RegionalReportServiceTrendTest` (3): 7 точек и раскладка счётчиков по месяцам (вне окна — игнор), фильтр вида
  доходит до запроса, область тенанта / пустая область.

## Как было ДО
Legacy `dashboard/ebus` показывал два графика за 6 месяцев назад + текущий по троллейбусам: число ПЛ по месяцам
(`Ebus\BillCountsController`) и пассажирооборот (`Ebus\PassengerVolumeController`). В e-Waybill на панели был только
оборот (автобус + троллейбус вместе, без выбора вида); счётчика ПЛ по месяцам не было.

## Как стало
Оба легаси-графика покрыты одной карточкой: число ПЛ (столбцы) + оборот (линия) по месяцам с выбором вида.
Число ПЛ считается по всем статусам созданных в месяце ПЛ (как legacy), оборот — по завершённым (как раньше).

## Почему
MIGRATION.md 6.8 — гэп паритета панели (Шаг 1 инвентаризации).

## Кто решил
Агент Claude по промпту Шага 2. Решение показать оба вида по умолчанию (а не только троллейбус, как legacy) —
сохранение прежнего поведения e-Waybill; троллейбус — одним кликом.
