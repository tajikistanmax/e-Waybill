# 5. Термины, определения и сокращения

## 5.1. Термины и определения

В настоящем техническом задании термины применяются в следующих значениях. Для терминов приводятся эквиваленты на государственном (таджикском) и английском языках; прочерк означает, что термин употребляется без перевода.

| Термин (рус.) | Термин (тадж.) | Термин (англ.) | Определение |
|---|---|---|---|
| Путевой лист | роҳхат | waybill | Документ, оформляемый на транспортное средство и водителя для выполнения перевозки; обязателен в силу Постановления Правительства РТ № 696 от 30.12.2009 |
| Электронный путевой лист (ЭПЛ) | роҳхати электронӣ | electronic waybill | Путевой лист, сформированный и подписанный в Платформе в электронной форме и имеющий юридическую силу по Закону РТ № 1965 |
| Товарно-транспортная накладная (ТТН) | борхат | consignment note | Документ на перевозимый груз, сопровождающий грузовую перевозку; формы — борхати замимаи 1, замимаи 2, международная CMR |
| Электронная ТТН (э-ТТН) | борхати электронӣ | e-consignment note | ТТН в электронной форме; предмет этапа 2 создания Платформы |
| Титул | титул | title | Логическая часть электронного документа, подписываемая одной ролью (диспетчер, медработник, механик и др.); подписанный титул неизменяем (см. раздел 3) |
| Электронная подпись (ЭП) | имзои электронӣ | electronic signature | Реквизит электронного документа по Закону РТ № 1965 от 15.03.2023, обеспечивающий подтверждение авторства и неизменности |
| РМА | рамзи мушаххаси андозсупоранда | taxpayer identification code | Идентификационный код налогоплательщика (9–10 цифр); ключ идентификации организаций, водителей и сотрудников в Платформе |
| Предрейсовый медицинский осмотр | муоинаи тиббӣ | pre-trip medical examination | Осмотр водителя медицинским работником до выезда; фиксируется отдельным титулом; для пассажирских и опасных перевозок предусматривается также послерейсовый осмотр |
| Контроль технического состояния (техконтроль) | муоинаи техникӣ | technical inspection | Предрейсовая проверка исправности транспортного средства механиком; фиксируется отдельным титулом |
| Диспетчер | танзимгар | dispatcher | Сотрудник перевозчика, формирующий путевой лист и сведения о рейсе |
| Водитель | ронанда | driver | Лицо, управляющее транспортным средством; путевой лист не подписывает, при проверке предъявляет QR-код; фиксирует приём и сдачу ТС |
| Медицинский работник (врач) | духтур | medical worker | Сотрудник, проводящий медосмотры водителей и подписывающий соответствующий титул |
| Механик | механик | mechanic | Сотрудник, проводящий техконтроль и подписывающий соответствующий титул |
| Стоянка | таваққуфгоҳ | depot / parking | Место базирования транспортного средства; номер стоянки — 4 цифры (1-я — колонна, 3–4-я — бригада) |
| Маршрут | хатсайр | route | Утверждённый маршрут перевозки; атрибуты — номер, вид маршрута, вид транспорта, регион |
| График | реҷа | schedule | Плановый график работы транспортного средства на маршруте |
| Круг | гардиш | round trip | Один оборотный рейс по маршруту; единица срока действия разовых форм («1 гардиш») |
| Клиент | мизоҷ | client | Заказчик перевозки (справочник клиентов) |
| Направление | самт | direction | Направление грузовой перевозки (справочник для формы 2-Б) с коэффициентами |
| Груз | бор | cargo | Перевозимый груз; атрибуты — наименование, вид, единица измерения, цена, класс |
| Прейскурант | нархнома | price list | Справочник тарифов за 1 км по видам транспортного средства, маршрута и топлива; основа расчёта стоимости услуг |
| Контрольная карточка | варақаи назоратӣ | control card | Документ допуска транспортного средства к перевозкам общего пользования; обязательна для организаций типа «истифодаи умум» |
| Дозвол | дозвол | permit | Разрешение на международную автомобильную перевозку; электронные дозволы выдаются в системе E-PERMIT |
| Вид сообщения | намуди ҳамлу нақл | type of service | Классификация перевозки: городская (шаҳрӣ), пригородная (наздишаҳрӣ), междугородная (байнишаҳрӣ), международная (байналмилалӣ) |
| Прицеп | ядак | trailer | Прицепное транспортное средство (до 2 на грузовой путевой лист) |
| Топливо | сузишворӣ | fuel | Вид топлива (бензин, дизельное, сжиженный газ, природный газ); учитывается выдача и переходящий остаток |
| Начальный пробег | гашти ибтидоӣ | initial run | Пробег от предприятия до начальной/конечной точки маршрута |
| Касса | хазина | cash receipts | Кассовая выручка по путевому листу формы 1-А |
| Книжка ББА | китобчаи ББА | BBA carnet | Книжка международной дорожной перевозки, реквизит формы 5Б-БМ (соотношение с книжкой МДП/TIR подлежит уточнению у заказчика) |
| Организация общего пользования | истифодаи умум | public carrier | Тип перевозчика, для которого обязательны лицензия и контрольная карточка |
| Ведомственная организация | соҳавӣ | departmental carrier | Перевозчик, выполняющий перевозки для собственных нужд |
| Агрегатор | агрегатор | aggregator | Организация (ЧУРА, НЕРУ и др.), оформляющая путевые листы через API Платформы в интересах перевозчиков |
| QR-код | QR-code | QR code | Машиночитаемый код на документе; содержит криптографически подписанные данные для проверки, в том числе офлайн (см. раздел 3) |
| ГИС ЭПД | — | GIS EPD | Государственная информационная система электронных перевозочных документов Минтранса России — референтная система титульной модели (см. раздел 3) |
| eCMR | — | eCMR | Дополнительный протокол к Конвенции КДПГ об электронной накладной; РТ — участник с 09.07.2019 |
| eTIR | — | eTIR | Цифровая система транзита МДП ЕЭК ООН; национальное приложение развёрнуто в РТ |
| E-PERMIT | — | E-PERMIT | Система электронных дозволов РТ (запущена 02.06.2026) с централизованным биллингом |
| Единая платформа (ЕП) | — | unified platform | Единая платформа управления транспортом Минтранса РТ — источник мастер-данных для Платформы (см. раздел 1) |
| ГУП ЦЦТО | — | SUE CDTI | ГУП «Центр цифровизации транспортной отрасли» — оператор Платформы |
| Удостоверяющий центр (УЦ) | — | certification authority | Организация, выдающая сертификаты ключей электронной подписи в соответствии с Законом РТ № 1965 |
| JWS | — | JSON Web Signature | Стандарт представления данных с электронной подписью в формате JSON; применяется для подписанной полезной нагрузки QR-кода и API |
| RBAC | — | role-based access control | Ролевая модель разграничения доступа пользователей Платформы |
