# Рабочий конспект: «Дастурамал» — руководство пользователя старой программы (2023)

> Источник: `docs\Роҳхат ПУТЕВОЙ ЛИСТ\МД«Наклиётиавтомобилйва_хизматрасониилогистикй».pdf` (76 стр., скан с частичным OCR). Программа ГУП «Наклиёти автомобилӣ ва хизматрасонии логистикӣ» (НА ва ХЛ) Минтранса РТ, доступ: http://94.199.18.153, вход по логину/паролю организации. Основание: Постановления Правительства РТ № 643 от 30.12.2011 («Об электронном правительстве») и № 642 от 30.12.2019 («Концепция цифровой экономики»).

## 1. Документы в системе

Путевые листы (роҳхатҳо): троллейбус Т(1-АД), автобус Т(1-АД), автобус/микроавтобус 1-А, сабукрав 3-С, шакли 2-Б (боркаш), шакли 5Б-БМ (грузовой международный), шакли 4М-БМ (пассажирский международный).
Накладные (борхатҳо): борхати замимаи 1, борхати замимаи 2, **CMR**.

## 2. Процессы (навиштан = создание, коркард = обработка/закрытие)

- **Создание ПЛ автобус/троллейбус/микроавтобус**: табельный номер, номер стоянки, номер маршрута, график (реҷа), начальный пробег (гашти ибтидоӣ — от предприятия до начала/конца маршрута); для заказных — номер клиента; для автобуса — вид топлива и «выдано топлива». Номер ПЛ, дата, время выезда, одометр, реквизиты предприятия — заполняются автоматически из массивов. Печать — Ctrl+P.
- **Создание 3-С (сабукрав)**: вид услуги — фармоишӣ (такси) / хатсайр (маршрут) / соатбайъ (почасовая); для такси — территория деятельности; для маршрута — номер/график/начальный пробег; для почасовой — клиент + территория.
- **Создание 2-Б (боркаш)**: вид перевозки корбайъ (сдельно)/соатбайъ (почасово), табель, стоянка, направление (самт), клиент.
- **Обработка (закрытие)**: время возврата, одометр возврата, время работы кондиционера, кол-во кругов, выручка, топливо (если за счёт организации); для 2-Б — номера борхатов замима 1/2. Микроавтобус 1-А обрабатывается до 4 дней, сабукрав — до 4 дней (в manual; в API-ТЗ до 7), 2-Б — до 7 дней (в manual; в API-ТЗ до 15); междугородный рейс грузовика — 1 день (1 гардиш). Поиск ПЛ по номеру для добавления дней 2–7.
- **QR-код**: на печатной форме ПЛ есть подпись «Барои гирифтани маълумоти бештар ё тафтиши роҳхат аз QR-code истифода баред» — проверка путевого листа по QR уже в старой системе.

## 3. Массивы (справочники) старой программы

1. **Корхонаҳо** (организации)
2. **Таваққуфгоҳ** (стоянки)
3. **Ронандаҳо** (водители)
4. **Минтақаҳо** (регионы)
5. **Шаҳрҳо** (города: код, страна, название)
6. **Тамғаҳо** (марки ТС): рақам, номгӯ (название), модель, ғунҷоиш (вместимость), иқтидори борбардорӣ (грузоподъёмность), маблағи хизматрасонӣ (стоимость услуги), гармкунии толор (отопление салона, л/час)
7. **Самтҳо** (направления): рақам, номгӯ, коэффициент внутригородской, экспорт/содирот, коэффициент зимний
8. **Давлатҳои хориҷӣ** (иностранные государства: рамз/код, номгӯ)
9. **Шаҳрҳои хориҷа** (иностранные города: код, страна, название)
10. **Сузишворӣ** (топливо: рамз, номгӯ)
11. **Коэффициенти зимистона** (зимний коэффициент: регион, коэффициент, срок с–по)
12. **Коэффициенти дохили шаҳр** (внутригородской: название, коэффициент)
13. **Коэффициенти баландкӯҳ** (высокогорный: название, коэффициент)
14. **Коэффициенти истифодабарӣ** (эксплуатационный/износа: год, километраж, коэффициент)
15. **Намуди хатсайрҳо** (виды маршрутов: рамз, номгӯ)
16. **Хатсайрҳои мусофирбарӣ** (пассажирские маршруты): рақам, номгӯ, намуди хатсайр, намуди нақлиёт, минтақа, шаҳр/ноҳия
17. **Мизоҷҳо** (клиенты): рақам, намуд, номгӯ, суроға, телефон
18. **Борҳо** (грузы): рақам, номгӯ, намуд, воҳиди ченаки бор (ед. измерения), нархи бор (цена), класи бор (класс груза)
19. **Нархнома** (прейскурант): рамз, намуди воситаи нақлиёт, намуди хатсайр, намуди сузишворӣ, нархнома барои 1 км (тариф за 1 км)
20. **Дараҷаҳои ронанда** (классы водителя): дараҷа, фоиз (% надбавки, напр. 20%)

→ Коэффициенты и нархнома нужны для **нормирования расхода топлива** и **расчёта стоимости/зарплаты** — этот функционал обязан сохраниться в новой платформе.

## 4. Отчёты (хисоботҳо)

Разделы: **мусофирбарӣ** (пассажирские), **боркашонӣ** (грузовые), **умумӣ** (общие).

Фильтры пассажирских/грузовых: дата (сегодня, вчера, текущий месяц, прошлый месяц, выбранные дни), тип ТС (автобус, микроавтобус, сабукрав…), вид отчёта, организация.
Виды отчётов: **автомобил** (по ТС), **ронанда** (по водителю), **тамға** (по маркам), **хатсайр** (по маршрутам), **музди меҳнати ронанда** (зарплата водителя), **дафтари қайди танзимгар** (журнал диспетчера), **ҳисоботи сузишворӣ** (по топливу).

Общие отчёты: по месяцам; по видам перевозок (2-Б, 5Б-БМ, 4М-БМ, мусофирбарӣ); «данные об исполнении перевозок»; «кол-во ТС, охваченных и обработанных путевых листов».

Статистика на главной: счётчики выданных ПЛ по типам ТС (пример на скриншоте: троллейбус 35241, автобус 264341, микроавтобус 18900, сабукрав 6984/4382).

## 5. Государственная статистическая отчётность

Печатная форма ПЛ = **бланк государственной статистической отчётности** (Замима/Приложение 7 к правилам): коды КУҶТ (организация-составитель), КУТОНХ (ведомство/территория), КШМ (форма собственности), КУРСХ (отрасль), КУФИ (вид деятельности). Номер бланка (напр. 0194651), серия. → В новом ТЗ учесть выгрузку данных для Агентства по статистике.

## 6. Прочее

- Печатная форма содержит: номер/серию, дату, реквизиты организации, водителя (ФИО, табель, ВУ, 20-часовые занятия), ТС (марка, госномер, контрольная карточка), маршрут, задание (супориш), расход топлива (норма/факт, литры), одометр, подписи, QR-код.
- Упоминается приёмка ТС водителем: «Троллейбусро (автобусро) қабул кардам» — «принял ТС» и «супоридам» — «сдал» (подписи водителя при приёме/сдаче ТС).
